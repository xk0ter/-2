# Task Manager

>Task Manager небольшое вебприложение
>веб-приложение для управления личными задачами.

## структура проекта
-[основные-возможности](#основные-возможности)
-[проект-использует](#проект-использует)
-[требования](#требования)
-[для-запуска](#для-запуска)
-[используемые-данные](#используемые-данные)

## основные-возможности
- создавать задачи
- просматривать список задач
- отмечать задачи как выполненные
- удалять задачи

## проект-использует
- HTML; -[сылка-на-документацию](https://developer.mozilla.org/ru/docs/Web/HTML)
- CSS;
- JavaScript;
- JSON.

## Требования
Для запуска проекта необходим:
- современный веб-браузер;
- локальная копия проекта.

### для-запуска
`Запуск
---
```bash
`src/index.html
`python -m http.server 8000\
`http://localhost:8000
```
### используемые-данные
Задачи приложения хранятся в файле:
---
```bash
`data/tasks.json
```
Пример структуры данных:
```bash
`[
    {
        "id": 1,"title":  
        "Подготовить документацию",
        "completed": false
    }
]
```
